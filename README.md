# Cursed Archive — Jujutsu Kaisen Field Documents

A fan-made, interactive editorial archive exploring cursed energy, sorcerers, Domain Expansion and the incidents that shape the Jujutsu Kaisen world.

## Stack
- React 19
- Vite 6
- CSS art direction and motion
- Original local artwork retained in `assets/`

## Design direction
An immersive field-document system combining Japanese editorial references, oversized condensed typography, expressive serif contrast, warm archival paper, charcoal ink, vermilion classification marks and acid-lime navigation accents. The layout uses asymmetric editorial grids, full-bleed imagery, subject files, timeline records and a live domain selector.

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The build copies the existing archive artwork into `dist/assets` so the original image library remains available without importing large binary assets into the JavaScript bundle.
